#### Responsibilities (TA):

- **Technical Mentorship**: Guided students through complex debugging processes and helped them translate abstract logic into functional code during interactive lab sessions.

- **Concept Breakdown**: Simplified foundational computer science concepts for introductory students to foster a strong grasp of algorithmic problem-solving.

- **Evaluation & Feedback**: Assessed programming assignments and examinations, providing constructive, code-level feedback to improve both student performance and code efficiency.
