#### Responsibilities (TA):

- **Technical Troubleshooting**: Assisted students in debugging complex shell scripts, managing file permissions, and resolving environment-specific terminal issues during interactive lab sessions.

- **Script Optimization & Evaluation**: Assessed student scripts for efficiency, robustness, and edge-case handling, ensuring code adhered to best practices for automation.

- **Practical Mentorship**: Guided students in transitioning from GUI-based interaction to utilizing powerful CLI tools (such as `grep`, `awk`, and `sed`) for efficient data processing and system administration.
